# CalcuMuestra Yarlequé — aplicación web

## Publicar
1. Sube `app.py` y `requirements.txt` a un repositorio de GitHub.
2. Entra en https://share.streamlit.io/ e inicia sesión con GitHub.
3. Selecciona Create app / Deploy an app.
4. Elige el repositorio, la rama `main` y escribe `app.py` como archivo principal.
5. Pulsa Deploy.

La aplicación incluye cálculo para proporciones y medias, corrección por población finita, ajuste por no respuesta y descarga de informe PDF. En variables numéricas, el margen de error debe estar en las mismas unidades que la desviación estándar. Revisa siempre los supuestos estadísticos antes de usar los resultados.
